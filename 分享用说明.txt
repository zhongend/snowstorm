【Snowstorm 积木粒子编辑器 · 分享版】

这是一个 Minecraft 基岩版粒子编辑器（Snowstorm）的改造版：
把原来"填表单"的编辑界面，改成了 Scratch 风格的积木拼图界面。
左边拖积木，右边 3D 预览实时变，做好的粒子可以导出 JSON 给 Minecraft 用。

────────────────────────
怎么打开（二选一）
────────────────────────

方式一：直接双击 index.html（最简单）
  解压后进入文件夹，双击 index.html 试试。
  如果页面空白或粒子不显示，请用方式二。

方式二：起一个本地小服务器（最稳，需要先装 Node.js）
  1. 到 https://nodejs.org 下载安装 Node.js（一路下一步）
  2. 在本文件夹的空白处按住 Shift 点鼠标右键 → "在此处打开 PowerShell 窗口"
  3. 输入：npx http-server -p 8080
  4. 打开浏览器，访问：http://localhost:8080

────────────────────────
怎么玩（30 秒上手）
────────────────────────
  1. 页面默认是"积木编辑"模式，左上角可以切换 传统编辑 / 积木编辑
  2. 左侧分类点开，把 [发射器]、[运动] 等积木拖进中间，接到 [粒子效果] 的竖槽下面
  3. 积木上的圆圈数字直接点击就能改；把 [粒子年龄]、[正弦] 这类小积木
     拖进数字槽，粒子就会"动"起来（比如旋转速度 = sin(粒子年龄 × 90)）
  4. 右边是实时 3D 预览，鼠标拖动转视角
  5. 顶栏按钮：▶运行 重新播放 | ⬇导出JSON 存成粒子文件 | 📃加载示例 一键看例子
  6. 导出的 JSON 放进 Minecraft 资源包的 particles 文件夹就能在游戏里用

改完代码后想重新打包：npm install 然后 npm run dev
